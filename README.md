# Переводчик — задание 0054

Логин: pavlovichvv. Приложение содержит одно поле input и один h1.
Введите русское слово: первый найденный английский перевод автоматически
появится в h1. Используется Яндекс.Словарь, направление ru-en.

## Настройка и сборка

Проверенная среда: Node.js 16.16.0, npm 8.11.0.
Скопируйте .env.example в .env.local и укажите свой ключ Яндекс.Словаря.
Этот файл исключён из Git, однако ключ виден в браузерной сборке.

```powershell
$env:Path = "$PWD\.tools\node-v16.16.0-win-x64;$env:Path"
npm ci
npm start
# Для публикации:
npm run build
```

App хранит введённое слово, Field отображает поле, Translate выполняет запрос
после паузы 300 мс и выводит результат. Очистка поля очищает заголовок;
устаревшие запросы отменяются. Ошибки отображаются отдельно от перевода.

## GitHub Pages

Исходники находятся в main. Содержимое build нужно разместить в корне
gh-pages: index.html и каталог static должны лежать рядом.
В Settings → Pages выберите Deploy from a branch, gh-pages, /(root).
homepage="." обеспечивает относительные пути к ресурсам.

После изменения ключа нужно повторно выполнить npm run build и обновить
содержимое gh-pages.
